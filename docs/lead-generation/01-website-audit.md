## 6. Technical, SEO, and Performance Health

### 6.1 Server & Infrastructure
* **Hosting Environment:** Microsoft-IIS/10.0 on Windows Server with Plesk (`X-Powered-By-Plesk: PleskWin`, `X-Powered-By: ASP.NET`).
* **Frontend Framework:** Angular Single Page Application (SPA) client build (`main-E6TK2O6S.js`, `polyfills-2UIMN3KP.js`, `scripts-D2AUHY22.js`).
* **Compression:** Brotli (`content-encoding: br`) is active, keeping initial HTML response small (~30KB–59KB compressed, ~233KB uncompressed).
* **TTFB (Time to First Byte):** 79ms to 203ms across sample tests, showing solid origin server responsiveness.

### 6.2 Critical SEO & On-Page Errors
1. **Production Title Tags Containing "test":**
   * `/contact`: `<title>d'furn - From Boardroom to Backyard test</title>`
   * `/service`: `<title>d'furn - From Boardroom to Backyard test</title>`
   * `/commercial`: `<title>d'furn - From Boardroom to Backyard test</title>`
   * `/hospitality`: `<title>d'furn - From Boardroom to Backyard test</title>`
   * `/residential`: `<title>d'furn - From Boardroom to Backyard test</title>`
   * *Impact:* Google indexes the word "test" in search engine result pages (SERPs), signaling an unfinished, unmaintained website.
2. **Third-Party Clinic Meta Description:**
   * `/about`: `<meta name="description" content="Confidental Clinic offers advanced and dental care in Asansol and Barakar, West Bengal. Visit the top-rated dentists for painless treatment">`
   * *Root Cause:* Agency developer copy-pasted a template from an unrelated dental clinic in West Bengal and failed to update the meta tag.
   * *Impact:* Google displays dental clinic text under D'furn's About page snippet in search results, completely destroying brand authority.
3. **Lorem Ipsum in Primary Heading:**
   * `/service`: `<h1>Lorem ipsum dolor sit amet consectetur adipisicing elit. Ipsam modi velit, et beatae quas perferendis ea neque inventore quod nesciunt magnam, laudantium voluptatum? Tempora magnam iste suscipit consequatur pariatur modi!</h1>`
   * *Impact:* Search crawlers index dummy Latin text as the primary topical anchor for company services.
4. **Duplicate Content Routing:**
   * `/commercial/workspaces` and `/commercial/workspaces/workstations` load the exact duplicate HTML bundle as the root homepage (`https://dfurn.in`), complete with `<link rel="canonical" href="https://dfurn.in">`.
   * *Impact:* Sub-category pages are completely cannibalized and cannot rank for high-intent keywords like "modular workstation manufacturer".
5. **Console-Breaking JavaScript Tag:**
   * `<script async src="https://www.instagram.com/dfurn.biz/"></script>` is embedded directly in the `<head>` of the application. Browsers attempt to parse an Instagram profile HTML page as executable JavaScript, triggering an uncaught syntax error on every visit.
6. **Schema Markup Incompleteness:**
   * `https://dfurn.in` has a basic `FurnitureStore` schema with corporate and factory addresses.
   * *Missing:* `Organization`, `Manufacturer`, `Product`, `AggregateRating`, `OpeningHoursSpecification`, and `AreaServed`. Inner pages have zero schema markup.
7. **Image Optimization Deficits:**
   * 50 out of 176 images on the homepage lack `alt` tags.
   * Only 6 out of 176 images use next-gen WebP format; the remainder are heavy PNG/JPEG assets served without responsive `srcset` scaling.
